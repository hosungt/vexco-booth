AI에게 바로 코드를 시키지 말고, 아래 틀에 맞춰 "기획"부터 채우면 훨씬 좋은 결과물이 나옵니다.

1. 기획 카드 — 네 조각을 채우세요

① 맥락과 목적
나는 누구이고, 무엇을 배우게 하려는가?
예시: "저는 중학교 2학년 수학 교사입니다. 학생들이 일차함수의 기울기 개념을 연습하면 좋겠어요."
② 작동
어떻게 작동하나? (조작 → 판정 → 피드백 → 종료 흐름)
예시: "문제를 보여주고 학생이 답을 고르면 바로 정답 여부를 알려주고, 틀리면 왜 틀렸는지 설명해 주세요. 10문제를 다 풀면 점수를 보여주세요."
③ 형태
결과물이 어떻게 생겼나? (화면 구성, 문항 수, 색·이모지)
예시: "스마트폰 화면에 문제 하나씩 보이게 해주시고, 파란색 계열로 깔끔하게 만들어 주세요. 문제는 10개로 해주세요."
④ 협업
아래 문장은 그대로 복사해서 붙여 넣으세요.
"바로 구현하지 말고 나와 함께 기획하면서 만들어 줘. 내가 놓친 것과 결정할 것이 있으면 최대 5개까지 물어보고, 답을 받으면 완전한 index.html 코드를 한 번에 출력해 줘."

2. 아이디어 점검 — 3가지 질문

종이보다 나은가? — 즉각 피드백·랜덤화·시간 압박·시뮬레이션·개별화 중 근거가 하나는 있어야 해요. "화려해서"는 근거가 아니에요.
학습이 일어나는가? — 학습자가 무엇을 하고, 어떤 피드백을 받는지 한 줄로 답해 보세요.
알맹이가 있는가? — 목표 개념 또는 겨냥하는 대표 오개념을 한 줄로 답해 보세요.

3. 집에서 웹 채팅으로 재현하는 5단계

① 생각뭘 만들지 떠올리고, 위 3가지 질문으로 점검해요.
② 물어보며 기획ChatGPT/Claude 새 채팅에 4조각을 채워 보내면 AI가 되물어요. 답해 주세요.
③ 만들기답을 다 하면 AI가 완전한 코드를 한 번에 만들어줘요.
④ 고치기미리보기를 보고 "이 부분 이렇게 바꿔줘"라고 말하면 돼요. 마음에 들 때까지 반복하세요.
⑤ 저장완성된 코드를 복사해 index.html 파일로 저장하세요. (뒷면 참고)

완성작을 인터넷에 올리기

GitHub Pages 배포 — 4단계
저장한 index.html을 아래 순서대로 올리면, 누구나 볼 수 있는 내 웹페이지가 생겨요.
1. 가입 또는 로그인
github.com 접속 → Sign up (계정이 있으면 Sign in) → 이메일 인증까지 완료
2. 저장소 만들기
New repository → 저장소 이름 입력(영문, 간단히) → Public 선택 → "Add a README file" 체크 → Create repository
3. 파일 올리기
저장소 화면에서 Add file → Upload files → index.html 파일을 끌어다 놓기 → Commit changes
4. Pages 켜기
Settings → Pages → Source를 "Deploy from a branch"로 선택 → Branch: main, 폴더: /(root) → Save
파일명은 반드시 index.html 이어야 해요.
다른 이름이면 페이지가 열리지 않아요.
잠시 후(보통 1분 이내) https://내계정명.github.io/저장소이름/ 에서 완성작을 확인할 수 있어요.
